| 指標 | 従来の行動選択 | 9＋3の課題成果学習 |
|---|---:|---:|
| 60日間の課題成功率 | 46.67% | **62.29%** |

## 内省の見方

「自分で感じた」という言葉はモデルが生成した**自己表現**です。現時点で検証できるのは、入力に含まれる実績との整合性、選んだ行動、予測と結果のずれ、次に検証したい仮説です。内部の主観や本当の感情は測定できません。
