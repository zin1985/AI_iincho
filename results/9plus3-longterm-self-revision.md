# 9＋3の長期自己更新ループ v1（2026-10-14）

## 実装済み

脳領域の客観的な成功/失敗の評価が、既存のN本人の日次内省を経由して長期的な方針へ戻るループを追加。

```text
検証済み課題成果 (本人と出典イベントIDが一致)
    ↓
9領域・3統合による観測と出典付き候補
    ↓
9＋3 方針見直し提案 (未承認、人格や感情を変更しない)
    ↓
Nの既存の日次AIレビュー (追加のLLM呼び出しなし)
    ├─ adopt  → 長期的な課題別方針を保存 → 次の小脳確率に限定反映
    ├─ defer  → 保留、方針不変
    ├─ reject → 拒否、方針不変
    └─ null   → 何も変更しない
    ↓
選択と客観的な結果を監査・次回レビューへ
```

## 3層を明確に分ける

1. **課題実績**：仮想世界のアクションが実行できたかとは別に、課題の採点を記録。未選択の行動は採点しない。
2. **機械による暫定的な方針候補**：同一課題の12件以上の採点済み結果、2つ以上の行動、各3件以上の観測、推定成功率差12ポイント以上から生成。
3. **本人モデルのレビュー**：本人が採用・保留・拒否。採用後も「課題に限った暫定戦略」であり、好き嫌い・感情・人格的信念として断定しない。

すべての提案・採用・結果には出典を残す。N本人によるレビューを経ずに機械判断を長期自己モデルへ上書きしない。別人格や合成データは本番Nの根拠にできない。

## 安全性

- Nの日次レビューに既存のLLMリクエストを追加しない。
- 睡眠・会話優先・行動の権限上限・創作10択の本人判断は変更しない。
- 既存の価値観・内省・過去の選択は上書きしない。
- 課題に限った選好の補正は logit 最大0.18、他の行動も選択可能なまま。
- 提案の期限は14日間。候補と方針は人格・課題単位で隔離。
- 本番Nの記録を公開GitHubへアップロードしない。
